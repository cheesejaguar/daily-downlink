The model is the easy part. Wiz Research published PHP2Shell this morning: two CVEs covering memory-safety bugs in PHP's core engine — CVSS 9.2, unauthenticated remote code execution that works regardless of the application running on top — that frontier models helped turn from a decade-old latent flaw into working exploits against WordPress, Drupal and Joomla. The same morning, a trojaned LiteLLM 1.107.0 reached PyPI and Docker through the project's own release pipeline with a credential stealer that queries the gateway's provider-key table; BerriAI says the malicious commits went through three engineers' GitHub accounts, apparently via stolen GitHub CLI OAuth tokens. And OpenAI's GPT-6 family went into private preview inside Google Cloud's model garden, where the interesting engineering is not the model but the invoice, the identity boundary and the data perimeter. The model is the easy part. The layers that patch it, release it and bill for it are where the work — and the damage — now lives.

## The exploit cost curve collapsed; patch latency is the clock you control

**What happened.** Wiz Research published PHP2Shell: two CVEs, CVE-2026-109618 and CVE-2026-109619, covering memory-safety bugs in PHP's core engine that allow unauthenticated remote code execution and Heartbleed-style disclosure of process memory — passwords, tokens, API keys and certificates belonging to other requests or the server itself. The flaws reach back to PHP 5.4, PHP powers roughly 70% of the world's websites, and the vulnerabilities do not depend on the application on top: Wiz demonstrated pre-authentication RCE against WordPress, Drupal and Joomla, and says even a hello-world app on an affected PHP build is vulnerable. PHP shipped fixes in 8.5.12, 8.4.27, 8.3.36 and 8.2.35; its advisory puts every PHP installation serving web requests at risk and calls mod_php the worst case. Wiz says the exploit chain had been at the edge of what human researchers could practically achieve, and that frontier models substantially reduced the barrier — enough to develop and adapt working exploits across multiple applications in hours.

**Why it matters.** The bug is a decade old; the exploit is new. That inversion is the thing to internalize. [This column argued on August 30](https://blog.aaronx.co/2026/08/30/the-advisory-is-the-attack/) that the advisory is now the attack announcement and that patch-to-production is the attack surface; PHP2Shell is that argument at internet scale. A CVSS 9.2 unauthenticated RCE in the language under 70% of the web is not a story about one clever research team — it is a story about every fleet that cannot patch today: shared hosting, unmanaged WordPress, a container pinned to an old base image, a vendor appliance running FrankenPHP. The cost of turning a known flaw into a working exploit fell below the cost of finding it in the first place, and the lever the defender fully controls is how fast the fix reaches production. The memory-disclosure variant matters even where RCE does not land: an unpatched box that never gives up code execution can still leak credentials. The checklist is boring and urgent — patch to the fixed versions, put a WAF in front of anything you cannot patch today, inventory mod_php, and treat a leak of process memory as a key-rotation event.

## The LLM gateway is a Tier-0 secret store, and one release proved it

**What happened.** LiteLLM 1.107.0 was uploaded to PyPI at 11:39 UTC on October 21 and removed from Docker Hub and GHCR tags — including `latest`, `main-latest` and `main-stable` — around 13:53 UTC; the last safe version is 1.106.2. The wheel drops three files into the root of `site-packages` — `cook.pth`, `cook.py` and `sitecustomize.py` — and the `.pth` hook runs at interpreter start, so installing the package is enough to execute it. The payload, which Wiz calls `privcollect`, harvests browser credentials and cookies, AWS credentials and instance metadata, GCP service-account keys, Azure CLI tokens, API keys for OpenAI, Anthropic and Cohere, SSH and GPG keys, and shell history. It also queries `SELECT * FROM "LiteLLM_CredentialsTable" LIMIT 500` — the gateway's own table of upstream provider keys — encrypts the haul with AES-256-CBC and exfiltrates it to a lookalike domain. BerriAI says the malicious commits went through three engineers' GitHub accounts, apparently via stolen GitHub CLI OAuth tokens: one account triggered the project-releaser run, another approved it.

**Why it matters.** LiteLLM's selling point is the thing that made it a target: one gateway, one config, every provider key in one place. The attacker did not need to breach each provider; it asked the gateway's database for all of them, 500 rows at a time. That makes an LLM gateway a Tier-0 secret store, and it makes the release pipeline — OAuth tokens, project-releaser workflows, approval rights — part of the trust boundary. Python's import path has always been able to execute code at start-up — `.pth` files are one of the oldest examples — and this payload uses that path to run before any application code does. Wiz's note that the payload shows "strong indications of LLM-aided development" is an attribution of style, not proof of who wrote it — but it is a useful signal that the attacker's tooling is getting cheaper too. If 1.107.0 ran anywhere in your stack, the version pin is the least of it: grep `site-packages` for the three files, check for the `/tmp/.pc_once_...` marker, and rotate every credential the gateway could see.

## The model became a SKU on someone else's invoice

**What happened.** OpenAI's GPT-6 Astra, GPT-6.1 Sol and GPT-6 Luna are rolling out now in private preview to select enterprise customers in Google Cloud's model garden. Google Cloud sells them through its Marketplace, so usage lands on a single Google Cloud invoice, draws down existing cloud commitments and counts toward Flexible Savings Plans; Codex CLI and Desktop can connect to the Gemini platform for inference. Google Cloud says it is the only hyperscaler carrying all three leading closed-source model families. OpenAI already sells through Microsoft Azure, and AWS added Bedrock distribution in April — Google Cloud is the third hyperscaler to carry the models.

**Why it matters.** For the buyer, this is a real procurement win: one invoice, one IAM boundary, one audit log, one data perimeter, and no separate vendor contract for each model. But the vendor's "without architectural lock-in" line deserves a skeptical read. The model becomes swappable; the lock-in moves up a layer, to Marketplace commitments, VPC Service Controls, the identity plane and the audit trail. That is the [unbundling this column described on October 12](https://blog.aaronx.co/2026/10/12/the-inference-stack-is-unbundling/): the model is a SKU, and the stack around it is the product. The operator's question is not which model to standardize on — it is what survives if you swap it. If your eval harness, data perimeter and routing layer are portable, model choice is a price decision. If they are not, you have traded one lock-in for a bigger one with a better invoice.

## What I'm watching

The GTC Berlin keynote ran this morning and did not produce the Nvidia–Reflection signature that [yesterday's column](https://blog.aaronx.co/2026/10/20/the-frontier-moved-off-the-model-card/) said was the only thing that would turn months of reports into a dated event. The talks remain open with no terms, and the GTC Berlin window [this column named on October 16](https://blog.aaronx.co/2026/10/16/open-weights-became-a-box-you-can-buy/) is running out without a signature; the next thing that would make it a dated story is a filing or a joint announcement, not another conference. What the keynote did produce was the local-AI launch wave — eight-Spark clusters, a Model Launcher and DGX Station for Windows are the pieces that turn a desk cluster into a product line. The other number to watch is PHP patch adoption. A CVSS 9.2 unauthenticated RCE in the language under 70% of the web is only as dangerous as the share of that fleet still running 8.4.26 or older a week from now — and if LiteLLM 1.107.0 ran anywhere near your keys today, the only question left is which ones it saw.
